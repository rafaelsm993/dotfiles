## Herdr keymap (prefix = `CTRL+Space`)

| Key | Action | Key | Action |
|---|---|---|---|
| `\` / `v` | split side by side | `-` | split stacked |
| `h j k l` | focus pane | `f` / `z` | zoom |
| `x` | close pane | `r` | resize mode |
| `[` | copy mode (`/` search) | `t` / `c` | new tab |
| `n` / `p` | next/prev tab | `1-9` | tab N |
| `,` | rename tab | `w` | close tab |
| `a` | workspace picker | `Shift+1-9` | workspace N |
| `g` | goto picker (agents) | `Alt+1-9` | agent N |
| `o` | jump to notifying agent | `Alt+g/y/s` | lazygit / yazi / shell popup |
| `?` | help | `q` | detach |

## Lessons (save future debugging time)

- **The outer terminal eats the prefix.** If WezTerm defines `CTRL+Space` anywhere,
  herdr never sees it. Check the WezTerm config that's *actually loaded* (on Windows,
  the copied file).
- **Always stow with `--no-folding`** and `mkdir -p ~/.config/<pkg>` first. Otherwise
  herdr writes `herdr-server.log`, `session.json` and sockets into the repo.
- **`herdr config check`** validates offline. `copy_mode` is valid even though it's
  missing from `herdr --default-config`; check https://herdr.dev/docs/config-reference/.
- **`herdr server` runs in the foreground.** For scripting use
  `herdr workspace create / pane split / pane run / pane read`.
- **Herdr panes run fish.** Test commands must be fish syntax: `(math 6 '*' 7)`,
  not `$((6*7))`.
- **Before renaming or merging, `git fetch`.** This session found the remote 8 commits
  ahead, with WSL work from the other machine.
- **CRLF:** several files were CRLF on the desktop and LF on GitHub. `core.autocrlf
  input` (set by bootstrap's `git` phase) keeps new commits LF.
